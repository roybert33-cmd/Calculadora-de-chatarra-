# Calculadora de Chatarra PWA - Deliverys Presss

App instalable como aplicacion nativa en Android / iPhone.

## Como subir a tu GitHub
1. Crea repo: calculadora-chatarra
2. Sube TODO lo de esta carpeta (index.html, manifest.json, sw.js, carpeta icons/)
3. Ve a Settings > Pages > Source: Deploy from branch -> main / root
4. Espera 1 min, tu link sera: https://TU_USUARIO.github.io/calculadora-chatarra/

## Como instalar en el telefono
- **Android (Chrome):** Abre el link > Menu (3 puntos) > Instalar app / Agregar a pantalla principal
- **iPhone (Safari):** Abre el link > Boton Compartir > Agregar a pantalla de inicio

Funciona SIN INTERNET despues de instalada.

## Funciones
- Precios: Fierro corto 120, Lata fierro 90, Aluminio 1000, Bronce 3500, Cobre 6000, Radiador aluminio 550, Radiador mixto 2500
- Agregar materiales personalizados
- Datos cliente: Nombre, RUT, Banco, N° Cuenta
- Guardar compras del dia
- Reporte diario con reinicio a cero automatico
- Envio directo a WhatsApp del jefe
- Historial de cierres
